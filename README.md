# It's Covered Website

Modern marquee-hire website and booking journey for It's Covered.

## Planned stack
- Next.js + TypeScript
- Vercel deployment
- Supabase for bookings, inventory and quote data
- Stripe for deposits/payments
- Mapping/route API for delivery calculations

## Customer journey
1. Pick your date
2. Tell us about your event
3. See recommended and available marquee packages
4. Add extras
5. Receive an initial quote
6. Reserve / pay deposit

## Admin goals
- Calendar view
- Stock-aware availability
- Booking management
- Quote management
- Deposit/payment tracking
- Inventory allocation

The live `itscovered.co.uk` domain will remain untouched until the replacement site is approved and ready to switch over.
